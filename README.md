# 전기기사 학습 가이드

`electric-engineer-course-guide.github.io` Organization의 루트 GitHub Pages용 정적 사이트입니다.

## 업로드 방법

1. GitHub에서 `electric-engineer-course-guide.github.io` 이름으로 Public Repository를 만듭니다.
2. ZIP의 압축을 푼 뒤 모든 파일을 Repository 최상단에 업로드합니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**로 선택합니다.
4. Branch는 **main**, 폴더는 **/(root)**로 설정하고 저장합니다.
5. 배포가 끝나면 사이트 주소에서 화면과 링크를 확인합니다.

별도 빌드 과정이나 프레임워크가 필요하지 않습니다.
